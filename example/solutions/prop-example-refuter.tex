\section*{Refutation: the centred sum of squares can vanish}
\label{sec:sol-prop-example-refuter}

\paragraph{What is being negated.}
\ref{conj:example} asserts, for \emph{every} finite real sequence with $n \ge 2$,
that $\sum_i (a_i - \bar a)^2 \ge \tfrac12 \sum_i a_i^2$. The statement is
universally quantified over sequences, so a single admissible instance on which it
fails negates it exactly (\texttt{CLAUDE.md} constraint 11). No family and no
limiting argument is required, because the claimed inequality is not uniform in any
parameter beyond the sequence itself.

\begin{theorem}[form of \ref{prop:example-refuter}]
\label{thm:sol-prop-example-refuter}
  Let $a = (1,1)$, so $n = 2$. Then $\sum_{i=1}^2 (a_i - \bar a)^2 = 0$ while
  $\tfrac12 \sum_{i=1}^2 a_i^2 = 1$. In particular
  $\sum_{i=1}^2 (a_i - \bar a)^2 < \tfrac12 \sum_{i=1}^2 a_i^2$.
\end{theorem}

\begin{proof}
  The sequence is admissible: it is real and has $n = 2 \ge 2$. Its mean is
  $\bar a = \tfrac12(1 + 1) = 1$, so $a_i - \bar a = 0$ for $i = 1,2$ and
  $\sum_{i=1}^2 (a_i - \bar a)^2 = 0$. Independently,
  $\sum_{i=1}^2 a_i^2 = 1 + 1 = 2$, so $\tfrac12\sum_{i=1}^2 a_i^2 = 1$. Since
  $0 < 1$, the asserted inequality fails at $a$. Every quantity here is an exact
  rational computed in closed form; no numerical evaluation enters the argument.

  The same conclusion follows from \ref{prop:example}, which gives
  $\sum_i (a_i - \bar a)^2 = \sum_i a_i^2 - n\bar a^2 = 2 - 2 = 0$; the direct
  computation above is recorded so the dossier stands alone.
\end{proof}

\paragraph{Obstructions respected.}
None apply. \ref{obs:example} fences establishing a \emph{universal} statement from a
finite battery; it explicitly leaves refutation open, which is the direction taken here,
and the witness is exact rather than sampled.
