\section{Orientation}
\label{sec:overview}

Replace this module. It exists so that a freshly cloned template is green under
every validator, and so that each artifact genre has one worked example to copy.

A convention this program fixes --- a sign, a scaling, a log base, which constant
absorbs what --- is stated here as a \texttt{\textbackslash begin\{definition\}}
under its own \texttt{\textbackslash label} and carries a ledger node with
\texttt{kind: definition} and \texttt{status: defined}. Claims resting on it name
it in \texttt{depends\_on}, so changing it is a mathematical edit the checker can
see. There is no separate notation or normalization file: a second list would be a
copy of the dependency graph that nothing keeps honest.

\subsection{An obstruction}

An obstruction is a fence: a statement violating it is wrong by construction, so
it is read \emph{before} a proof is attempted or a numerical run is spent
(\texttt{CLAUDE.md} constraint 5). It is an ordinary ledger node --- \texttt{kind:
obstruction}, stated here in an \texttt{obstruction} environment under a
\texttt{\textbackslash label} like any other claim ---
and it is stated here, rather than in a registry of its own, because a fence is
only useful next to the mathematics it fences.

State both halves. An obstruction that records only what it rules out, or only
that something is hard, fences nothing: the escape routes are what the next agent
reads.

\begin{obstruction}[worked example of an obstruction]
\label{obs:example}
  \emph{Rules out.} Establishing a universal statement from a finite battery of
  instances. Agreement across every instance tried constrains nothing about the
  untried ones, so no run --- however large --- discharges a universal claim.

  \emph{Leaves open.} Refutation. One instance suffices to refute a universal
  statement, and an exact arithmetic witness for such an instance is a genuine
  candidate --- though it still requires an independently reviewed refutation
  dossier before it carries logical force (\texttt{CLAUDE.md} constraint 2).
\end{obstruction}

\subsection{An open question}

An \texttt{open} node is one nobody has discharged. It carries no proof provenance,
and saying it is ``probably true'' is not a ledger classification --- the question
below is elementary and almost certainly has a one-line proof, and it stays
\texttt{open} until someone writes that proof into a dossier and a reviewer checks
it. Status records what has been established, never what is expected.

\begin{question}
\label{q:example}
  Does \ref{prop:example} survive weighting? Fix weights $w_1,\dots,w_n > 0$ with
  $\sum_{i=1}^n w_i = 1$ and write $\bar a_w = \sum_{i=1}^n w_i a_i$. Is
  \[
    \sum_{i=1}^n w_i (a_i - \bar a_w)^2 = \sum_{i=1}^n w_i a_i^2 - \bar a_w^2
  \]
  for all real $a_1,\dots,a_n$?
\end{question}

\subsection{A proved statement}

\begin{proposition}
\label{prop:example}
  Let $a_1,\dots,a_n$ be real numbers and let $\bar a = n^{-1}\sum_{i=1}^n a_i$.
  Then $\sum_{i=1}^n (a_i - \bar a)^2 = \sum_{i=1}^n a_i^2 - n \bar a^2$.
\end{proposition}

The proof is a standalone dossier, \texttt{solutions/prop-example.tex}, certified
by an independent review under \texttt{research/reviews/}. The manuscript states
the result; the dossier is what an independent reviewer checks
(\texttt{solutions/README.md}).

\subsection{A refuted conjecture --- the worked search's target}

This is the statement the example's problem brief and search portfolio are organized
around, and the one the routes attack. Refutation ends where proof ends: in a
certified dossier. The witness itself is
not the refutation --- it is a candidate until the statement it establishes is a
node of its own, proved and independently reviewed. Only then does the target
become \texttt{refuted}, naming that node in \texttt{refuted\_by} and nowhere
else. The refuter is \emph{not} a \texttt{depends\_on} of what it refutes: that
field records facts a proof used, and a refuted statement has no proof.

\begin{conjecture}
\label{conj:example}
  For all real $a_1,\dots,a_n$ with $n \ge 2$,
  $\sum_{i=1}^n (a_i - \bar a)^2 \ge \tfrac{1}{2}\sum_{i=1}^n a_i^2$.
\end{conjecture}

\begin{proposition}
\label{prop:example-refuter}
  The sequence $a = (1,1)$ satisfies $\sum_{i=1}^2 (a_i - \bar a)^2 = 0$ and
  $\tfrac{1}{2}\sum_{i=1}^2 a_i^2 = 1$. Hence \ref{conj:example} is false.
\end{proposition}

One instance suffices because the conjecture is universally quantified over
sequences. A dimension-free or uniform constant would instead need a certified
family along which the relevant quantity diverges (\texttt{CLAUDE.md}
constraint 10).
